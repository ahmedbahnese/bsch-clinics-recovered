# Android wrapper

هذا مجلد Android WebView خفيف يفتح نسخة BSCH Clinics كـ PWA/ويب. مناسب للأجهزة الضعيفة لأن الواجهة خفيفة ولا تستخدم مكتبات ضخمة.

- ضع عنوان الخادم في `app/src/main/java/com/bsch/clinics/MainActivity.java`.
- البناء: Android Studio قديم أو Gradle متوافق مع بيئة البناء.
- يمكن أيضاً تثبيت الموقع من Chrome/Edge عبر Add to Home Screen بدون APK.

لأسباب تتعلق بمساحة وأدوات Sandbox، لم أضع APK ثنائي غير مختبر في GitHub؛ الكود المصدر وPWA هما النسخة القابلة لإعادة البناء.
