# تطبيق Android — العيادات الخارجية

نسخة Android WebView خفيفة تعمل على Android 6.0+، وتفتح خادم العيادات الداخلي مباشرة.

## الاستخدام

عند أول تشغيل سيظهر مربع **إعداد خادم المستشفى**. اكتب عنوان الخادم الداخلي، مثل:

```text
http://192.168.1.10:4173/
```

يتم حفظ العنوان على الهاتف. لإعادة تغييره احذف بيانات التطبيق من إعدادات Android أو أعد بناء التطبيق بعنوان افتراضي جديد.

## البناء

```bash
gradle assembleRelease
```

الناتج يكون في `app/build/outputs/apk/release/`.

> يلزم أن يكون الهاتف على نفس شبكة المستشفى وأن يسمح جدار الحماية بالاتصال بمنفذ Flask الداخلي.
