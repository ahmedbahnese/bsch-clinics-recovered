# تطبيق Android Offline — العيادات الخارجية

هذه النسخة تعمل بالكامل على الهاتف بدون Internet وبدون Backend أو خادم خارجي. البيانات محفوظة محلياً داخل WebView في قاعدة تخزين الهاتف.

## الوظائف

- الرئيسية.
- حجز موعد داخلي للموظف.
- متابعة حجز برقم الحجز والهاتف.
- شاشة الانتظار.
- شاشة إدارة الدور: نداء، التالي/تم الكشف، تخطي، رجوع.
- كشف الحجوزات والبحث بالاسم أو الهاتف أو رقم الحجز.
- الإعدادات محمية بكلمة مرور.
- العيادات الحالية داخل التطبيق.
- تصدير واستيراد النسخ الاحتياطية بصيغة JSON.
- تغيير كلمة مرور الإعدادات.

كلمة المرور الافتراضية للإعدادات هي:

```text
bsch
```

غيّرها من شاشة الإعدادات بعد أول تشغيل.

## الاستخدام

لا تظهر شاشة إعداد خادم؛ التطبيق لا يتصل بأي شبكة. افتح التطبيق وابدأ بالحجز الداخلي.

## البناء

```bash
gradle assembleRelease
```

الناتج يكون في `app/build/outputs/apk/release/`. النسخة الجاهزة باسم `BSCHClinics-Android-Offline-v1.2.1.apk`.
