# تطبيق Android محلي — العيادات الخارجية

نسخة Android تعمل بنفس واجهة النسخة Online، لكن بدون Domain أو موقع أو Backend خارجي. كل هاتف يحتفظ ببياناته محلياً فقط.

## الوظائف المحلية

- الرئيسية والحجز الداخلي.
- متابعة الحجز.
- شاشة الانتظار وشاشة الدور.
- كشف الحجوزات والبحث.
- الإعدادات.
- العيادات.
- النسخ الاحتياطي والاستعادة.
- تغيير كلمة المرور.
- حفظ البيانات على الهاتف فقط.

كلمة المرور الافتراضية للإعدادات:

```text
bsch
```

لا يحتاج التطبيق إلى إنترنت أو Wi-Fi أو دومين.
