# أوضاع التشغيل

## Standalone Offline

Backend وSQLite على نفس الجهاز، والحجز الداخلي والدور والتقارير والطباعة تعمل بدون Internet. القنوات الخارجية وAI السحابي متوقفة Server-Side.

## Hospital Server / Local Network

Backend وSQLite على خادم المستشفى. أجهزة Windows وAndroid والمتصفحات تتصل بعنوان داخلي. لا تعتمد الوظائف الداخلية على Cloud.

## Online / Cloud

يشغل المدير الوضع Online من لوحة التحكم أو يحدد `BSCH_OPERATING_MODE=online`. يمكن تفعيل القنوات الخارجية وAI من الإعدادات، لكنها اختيارية ولا توقف الحجز الداخلي عند تعطيلها.

## الصلاحيات

قراءة الإعدادات للمدير، وتغيير وضع التشغيل للمؤسس فقط عبر `PATCH /api/settings`. لا يتم تشغيل WhatsApp/Telegram أو AI الخارجي إلا في Online ومع تفعيل صريح.

## الانتقال

قبل الانتقال خذ نسخة من `bsch_clinics.sqlite3`. لا تنقل قاعدة البيانات بين وضعين متزامنين في الوقت نفسه؛ استخدم نسخة واحدة مرجعية لتجنب التكرار. يمكن تشغيل نفس Backend على العنوان الجديد مع الاحتفاظ بقاعدة SQLite.
