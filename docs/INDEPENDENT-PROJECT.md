# مشروع مستقل عن Whacka

هذا المشروع هو «العيادات الخارجية» بكامل Backend وFrontend وقاعدة SQLite والمنطق البرمجي داخل GitHub. لا توجد خدمة تشغيلية أو API ضرورية من Whacka.

## الأوضاع

- `online`: Backend على خادم عام، ويمكن تفعيل AI وWhatsApp/Telegram عبر متغيرات البيئة والخدمات الخاصة بالمؤسسة.
- `hospital_server`: Backend وقاعدة البيانات على خادم داخل المستشفى، وتصل إليه أجهزة Android وWindows بعنوان قابل للتغيير.
- `standalone_offline`: Backend وSQLite على جهاز واحد، وتعمل الوظائف الداخلية بدون Internet.

## حدود الاتصال

الحجز الداخلي، المستخدمون، الدور، التقارير، القوالب، التدقيق والجدولة تعمل محلياً في كل الأوضاع. AI الخارجي وWhatsApp وTelegram تحتاج Online ومفاتيح/موصلات المؤسسة، ولا يتم تفعيلها تلقائياً في الوضع المحلي.

## أمن البيانات

لا تضع مفاتيح أو كلمات مرور أو قواعد مرضى حقيقية في Git. استخدم `.env.example` ونسخاً احتياطية محمية.
