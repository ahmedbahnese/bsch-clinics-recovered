# BSCH Clinics — العيادات الخارجية

نظام عربي RTL لحجز العيادات الخارجية وإدارة تأكيد الحجز والدور والنداء، مع نسخة Web/PWA وملفات تغليف Android وWindows 7 ‏32-bit للأجهزة الضعيفة.

## المتطلبات المنفذة

- استبدال عنوان الصفحة الأولى إلى **العيادات الخارجية**.
- الحجز بالاسم رباعي، السن، العنوان، الهاتف، العيادة، نوع الخدمة، اليوم والموعد.
- تحقق Server-Side من اليوم المسموح، نوع الخدمة، الخدمة بالحضور المباشر، والعدد الأقصى لكل عيادة/خدمة/يوم.
- بيانات العيادات والخدمات والأيام والأعداد والأوراق والتعليمات قابلة للتعديل من API موظف الحجز، وليست نصوصاً ثابتة في الواجهة.
- تأكيد الحجز من موظف الحجز مع رقم دخول متسلسل.
- صفحة تأكيد A4 تحتوي على كل بيانات الحجز وتعليمات العيادة والخدمة المحددة فقط.
- طباعة الإيصال أو اختيار Save as PDF من نافذة الطباعة.
- زر مشاركة الهاتف باستخدام Web Share API عند توفره، أو نسخ بيانات الحجز.
- شاشة الانتظار وإجراءات Queue.
- سجلات حقيقية: Users, Clinics, ClinicSchedules, Bookings, QueueEntries, QueueEvents, Transfers, Notifications, AuditLogs.

## العيادات المبدئية

تم تحميل العيادات الست المطلوبة في قاعدة Demo:

1. الجهاز الهضمي — السبت والثلاثاء — 75.
2. التغذية — الأحد والأربعاء والخميس — 50.
3. النفسية والعصبية — السبت — 15.
4. الأسنان — كل الأيام عدا الجمعة — خلع/حشو — 4.
5. الإيكو — كل الأيام عدا الجمعة — 5، مع تعليمات الحضور 8:30 وكلورال هيدرات وأعراض البرد.
6. السمعيات — كل الأيام عدا الجمعة — خدمات رسم السمع، والحالات بالحضور المباشر مرفوضة إلكترونياً.

> ترقيم الأيام في الكود هو Python weekday: الاثنين 0، الثلاثاء 1، ... السبت 5، الأحد 6.

## التشغيل Web/PWA

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

افتح `http://127.0.0.1:4173`. ويمكن تثبيت الموقع من متصفح الهاتف عبر **Add to Home Screen**؛ ملفات `manifest.json` و`sw.js` موجودة في `static/`.

## Android

المصدر موجود في `mobile/android/` كتطبيق WebView خفيف يدعم الأجهزة الضعيفة. غيّر `server_url` في `res/values/strings.xml` إلى عنوان الخادم ثم ابنِ من Android Studio/Gradle. كما أن PWA هي الخيار الأخف ولا تحتاج APK.

## Windows 7 32-bit

المصدر موجود في `desktop/windows7-ia32/` ويستخدم Electron 13.6.9 مع `ia32` لاستهداف Windows 7 القديم:

```bash
npm install
npm run package:win32
```

يحتاج البرنامج إلى خادم Flask متاح ويعرض العنوان الموجود في `BSCH_SERVER_URL` أو العنوان الافتراضي. تم اختيار Electron legacy بدلاً من WebView2 لأنه لا يعتمد على WebView2 الحديث غير المناسب لويندوز 7.

## قواعد البيانات والخصوصية

- `data/bsch_clinics_demo.sqlite3` قاعدة Demo معقمة تحتوي على المخطط والحسابات والعيادات المبدئية فقط، ومرفوعة عمداً إلى GitHub لتسهيل التجربة.
- `bsch_clinics.sqlite3` قاعدة التشغيل المحلية مستبعدة من Git لأنها قد تحتوي على بيانات مرضى.
- `backups/` مستبعدة من Git وتحتوي فقط على نسخة محلية قبل الترقية.
- لا يتم رفع سجلات مرضى حقيقية أو كلمات مرور تشغيلية أو مفاتيح سرية إلى GitHub. عند استخدام النظام الفعلي، خزّن قاعدة التشغيل على الخادم مع نسخ احتياطية محمية.
