# BSCH Clinics — Recovered Web Snapshot

نسخة قابلة للتشغيل والتعديل من الموقع المنشور:
<https://bsch-clinics-6io8.whacka.app>

## ما تم استعادته

- واجهة التطبيق المجمعة JavaScript/CSS.
- HTML shell وPWA manifest.
- الأيقونات وصور الـ splash واللوجو/الصورة الرئيسية.
- نفس المسارات الظاهرة في النسخة المنشورة: الرئيسية، حجز موعد، متابعة حجز، شاشة الانتظار، ودخول الموظفين.

## التشغيل محلياً

```bash
npm start
# افتح http://localhost:4173
```

## ملاحظة مهمة عن المصدر الأصلي

الموقع المنشور يتيح ملفات build فقط (`index.js` و`index.css`) ولم يوفّر source maps أو ملفات React/TypeScript الأصلية. لذلك هذه **نسخة recovered build** قابلة للتشغيل، وليست استعادة حرفية لبنية المشروع الأصلية قبل البناء.

التطبيق الأصلي يعتمد على خدمات Whacka/Supabase للبيانات، المصادقة، والتحديثات اللحظية. الواجهة والأصول المحلية موجودة هنا، أما نقل الـ backend بشكل مستقل فيحتاج تصدير المشروع الأصلي أو إعداد Supabase جديد مع مخطط قاعدة البيانات وقواعد RLS.

## الخطوة التالية للتطوير

يفضل إعادة تنظيم `assets/index-VHKWH2dv.js` إلى مشروع React/Vite بمكونات واضحة بعد توفير تصدير المصدر الأصلي من منصة Whacka. يمكن استخدام هذه النسخة كمرجع بصري وتشغيلي أثناء إعادة البناء.
