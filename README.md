
## الحزم الجاهزة للإصدار 1.1.0

تم تجهيز الحزم التالية في GitHub Release:

- `BSCHClinics-Android-v1.1.apk`: تطبيق Android موقّع وقابل للتثبيت. عند أول تشغيل يطلب عنوان خادم المستشفى الداخلي.
- `BSCHClinics-win32-ia32.zip`: نسخة Windows 7 ‏32-bit خفيفة. بعد فك الضغط انسخ `server-url.example.txt` إلى `server-url.txt` وضع عنوان الخادم الداخلي، ثم شغّل `BSCHClinics.exe`.

مثال عنوان داخلي:

```text
http://192.168.1.10:4173/
```

يجب تشغيل Flask على جهاز داخل المستشفى ليستمع على الشبكة، مثلاً:

```bash
python3 app.py
```

وتأكد من فتح المنفذ 4173 في جدار الحماية والسماح للأجهزة على شبكة المستشفى بالوصول إليه. لا يمكن تثبيت عنوان داخلي فعلي داخل الحزم قبل معرفة IP أو اسم DNS الخاص بخادم المستشفى، لذلك جعلت العنوان قابلاً للإعداد عند أول تشغيل في Android ومن ملف `server-url.txt` في Windows.
