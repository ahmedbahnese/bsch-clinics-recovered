# BSCH Clinics — العيادات الخارجية

نظام عربي RTL لحجز العيادات الخارجية وإدارة تأكيد الحجز والدور والنداء، مع نسخة Web/PWA وملفات تغليف Android وWindows 7 ‏32-bit للأجهزة الضعيفة.

> النظام مخصص لإدارة **الحجوزات والانتظار فقط**، وليس EMR ولا يخزن سجلاً طبياً متكاملاً ولا يتخذ قرارات طبية.

## المتطلبات المنفذة

- الصفحة الرئيسية باسم **العيادات الخارجية**.
- حجز بالاسم رباعي، السن، العنوان، الهاتف، الرقم القومي الاختياري، العيادة، الخدمة، اليوم والموعد.
- تحقق Server-Side من الأيام، الإجازات، ساعات الخدمة، السعة اليومية، والخدمات بالحضور المباشر.
- منع الحجز المكرر بالاسم + الهاتف + الرقم القومي إن وجد + العيادة + التاريخ، مع إرجاع الحجز المشابه للمراجعة.
- تأكيد الحجز من موظف الحجز وإصدار رقم دخول.
- صفحة تأكيد A4 وتعليمات العيادة والخدمة والطباعة والمشاركة.
- شاشة الانتظار وإجراءات: نداء، داخل الكشف، تم الكشف، تخطي، لم يحضر، وإعادة.

## قوالب الرسائل

من لوحة التحكم يمكن للمؤسس إنشاء وتعديل ومعاينة واختبار قوالب:

- الترحيب.
- البيانات الناقصة.
- تأكيد الحجز.
- الإلغاء.
- إعادة الجدولة.
- عدم توفر العيادة.
- متابعة رقم الانتظار.
- تعليمات الحضور.

المتغيرات المدعومة:

```text
{{patientName}} {{clinicName}} {{clinicDays}} {{workingHours}}
{{queueNumber}} {{trackingLink}} {{hospitalName}} {{serviceType}}
{{appointmentDate}} {{appointmentTime}} {{missingFields}}
{{attendanceInstructions}} {{documents}}
```

## تحليل رسائل WhatsApp وTelegram

المسار `POST /api/messages/incoming` يستقبل رسالة من أي قناة مدعومة، ويقوم Server-Side بـ:

1. استخراج الاسم والسن والهاتف والعيادة والخدمة واليوم والساعة والرقم القومي إن وجد.
2. مقارنة العيادة والخدمة بقاعدة البيانات.
3. تحديد البيانات الناقصة أو غير الواضحة.
4. إنشاء رد باستخدام قالب البيانات الناقصة.
5. إنشاء طلب حجز للمراجعة فقط بعد اكتمال البيانات.

يستخدم الذكاء الاصطناعي المتصل عبر `OPENAI_API_KEY` و`OPENAI_API_BASE` مخرج JSON منظم. عند عدم وجود اتصال أو مفاتيح، يوجد محلل احتياطي محدود لاستخراج الأرقام والأسماء وأسماء العيادات. **لا يؤكد الذكاء الاصطناعي الحجز ولا يتخذ أي قرار طبي**؛ تأكيد موظف الحجز إلزامي.

## التقارير

من لوحة التحكم يمكن التصفية حسب:

- العيادة.
- التاريخ.
- حالة الحجز.
- مصدر الحجز: `system`, `manual`, `whatsapp`, `telegram`.

وتعرض التقارير الإجمالي، المؤكد، الملغى، لم يحضر، تم الكشف، المنتظر، مصادر الحجز، أرقام الانتظار، ومتوسط وقت الانتظار. التصدير متاح بصيغ CSV وExcel XLSX وHTML للطباعة/الحفظ PDF وWord-compatible HTML.

## إدارة جدول العيادات

- أيام العمل الأسبوعية وساعات العمل الأساسية.
- مدة الكشف والسعة اليومية.
- جدول خدمة مستقل حسب اليوم والساعة والسعة.
- إيقاف الحجز في يوم محدد مع الحفاظ على الحجوزات الموجودة.
- تسجيل إجازات العيادة.
- إضافة أكثر من طبيب للعيادة مع يوم وساعات الطبيب.
- تشغيل/إيقاف العيادة من صلاحيات المؤسس أو موظف الحجز.

## سجل التدقيق والرسائل

تسجل قاعدة البيانات إنشاء وتأكيد وتعديل وإلغاء وإعادة جدولة ونقل الحجز، تغييرات الدور، المستخدم المنفذ، الوقت، ومصدر الحجز. كما تحفظ الرسائل الواردة والصادرة، القالب المستخدم، الحالة، المحاولات، وأخطاء الإرسال لإتاحة إعادة المحاولة لاحقاً.

## العيادات المبدئية

1. الجهاز الهضمي — السبت والثلاثاء — 75.
2. التغذية — الأحد والأربعاء والخميس — 50.
3. النفسية والعصبية — السبت — 15.
4. الأسنان — كل الأيام عدا الجمعة — خلع/حشو — 4.
5. الإيكو — كل الأيام عدا الجمعة — 5، مع تعليمات الحضور 8:30 وكلورال هيدرات وأعراض البرد.
6. السمعيات — كل الأيام عدا الجمعة — خدمات رسم السمع، والحالات بالحضور المباشر مرفوضة إلكترونياً.

> ترقيم الأيام في الكود هو Python weekday: الاثنين 0، الثلاثاء 1، ... السبت 5، الأحد 6.

## التشغيل Web/PWA

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

افتح `http://127.0.0.1:4173`. ويمكن تثبيت الموقع من الهاتف عبر **Add to Home Screen**؛ ملفات `manifest.json` و`sw.js` موجودة في `static/`.

## Android

المصدر موجود في `mobile/android/` كتطبيق WebView خفيف. غيّر `server_url` في `res/values/strings.xml` ثم ابنِ من Android Studio/Gradle. كما أن PWA هي الخيار الأخف ولا تحتاج APK.

## Windows 7 32-bit

المصدر والحزمة المضغوطة موجودان في `desktop/windows7-ia32/` ويستخدمان Electron 13.6.9 مع `ia32`:

```bash
npm install
npm run package:win32
```

## الاختبارات

تم اختبار Python وJavaScript، ترحيل قاعدة SQLite، القوالب والمعاينة والاختبار، تحليل رسالة كاملة بالذكاء الاصطناعي، طلب البيانات الناقصة، إنشاء طلب WhatsApp للمراجعة، منع التكرار، إغلاق يوم محدد، التقارير والتصدير، سجل التدقيق، وملفات PWA.
